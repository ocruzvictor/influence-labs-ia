Tipos extras neste domínio (além de integração/validação/automação/notificação/cálculo/transformação):

| Tipo | Gatilho Tess |
|---|---|
| `deterministico-hotpath` | Já é código (intent, guards, Nightwatch) — candidato a CLI/ops, não a reescrever |
| `orcamento-contexto` | Medir/cortar chars por perfil sem chamar Tess |
| `correlacao` | trace_id / last4 / verify / orphans |
| `visibilidade` | CRM-lite / etapa do fio para o salão (H-CRM = hipótese) |
