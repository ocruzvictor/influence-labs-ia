# Roteiro de Reuniao - Discovery Salao

## Abertura (5 min)
- Objetivo da reuniao: mapear operacao atual para configurar recepcionista IA + vendas/follow-up.
- Confirmar responsavel final por aprovacoes: [NOME]

## Bloco 1 - Servicos
- [ ] Lista completa de servicos
- [ ] Preco de cada servico
- [ ] Duracao media
- [ ] Combos/pacotes
- [ ] Servicos que exigem profissional especifico

## Bloco 2 - Profissionais
- [ ] Lista de profissionais e especialidades
- [ ] Horarios de trabalho
- [ ] Folgas/rodizio
- [ ] Regras de capacidade simultanea

## Bloco 3 - Agendamento
- [ ] Processo atual (como funciona hoje)
- [ ] Regras de antecedencia
- [ ] Politica de cancelamento/reagendamento
- [ ] Lista de espera
- [ ] Horario de funcionamento
- [ ] Intervalo entre atendimentos

## Bloco 4 - Comunicacao
- [ ] Tom de voz do agente
- [ ] Nome do agente
- [ ] Frases comuns da dona
- [ ] Frases proibidas
- [ ] Top 10 FAQs reais
- [ ] Tratamento de reclamacoes

## Bloco 5 - Vendas Proativas
- [ ] Promocoes recorrentes
- [ ] Regras de cross-sell
- [ ] Frequencia de follow-up
- [ ] Janela de reativacao (dias)
- [ ] Datas especiais

## Bloco 6 - Coexistencia (IA + Humano)
- [ ] Em quais casos notificar a dona
- [ ] Casos obrigatorios de handoff
- [ ] Horarios IA 100% autonoma
- [ ] Disponibilidade para operar Chatwoot

## Encerramento (10 min)
- [ ] Recapitular decisoes
- [ ] Validar pendencias abertas
- [ ] Agendar revisao final da KB
