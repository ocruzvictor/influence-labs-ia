1. **Não esquecer:** Cookie `Secure` deve ser `false` em dev (NODE_ENV !== 'production'), `true` em prod. Detectar via `env.NODE_ENV`.
2. **Rate limit:** LRU em memória pra `/api/auth/magic-link` (3 req/min/email). Lib `lru-cache` já instalada.
3. **CSP em `next.config.ts`:** ver `frontend/admin/node_modules/next/dist/docs/01-app/02-guides/content-security-policy.md` pra padrão atualizado.
4. **shadcn + Tailwind v4:** o `npx shadcn@latest init` detecta v4 automaticamente. Estilo: "New York", base color: "Stone" pra match com paleta cream/navy.
5. **Resend types:** API v6+. Método `resend.emails.send()` retorna `{ data, error }` — checar `error` antes de assumir sucesso.
6. **Build test:** `npm run build` provavelmente vai falhar sem `.env.local` setado (Zod fail-fast). Solução: ou criar `.env.local` com valores dummy só pra build, ou refatorar `env.ts` pra validar lazy. Recomendo dummy values pra preservar fail-fast.
