Como Funciona

Processo de trabalho.

Sessao 1 - Discovery & Setup (4h)

  • Analisamos 20-30 posts/videos seus para mapear tom de voz.
  • Definimos criterios de historias que funcionam.
  • Testamos buscas de historias em tempo real.
  • Geramos 3-5 roteiros na hora para validar.
  • Formato: 50% conversa estrategica + 50% construcao hands-on.

Voce recebe: Documento de Tom de Voz + Primeiros Roteiros.

Trabalho Assincrono (7-10 dias)

  • Desenvolvemos o agente de busca de historias.
  • Refinamos prompts de geracao.
  • Criamos banco com 50-100 historias curadas.
  • Geramos 10-15 roteiros de teste.
  • Formato: trabalho focado da equipe + updates para acompanhamento.

Voce recebe: Sistema funcionando + Roteiros de teste.

Sessao 2 - Apresentacao & Ajustes (3h)

  • Apresentamos o sistema completo.
  • Testamos geracao ao vivo.
  • Ajustes finos com seu feedback.
  • Geramos lote adicional de roteiros.
  • Formato: 50% demonstracao + 50% ajustes colaborativos.

Voce recebe: Sistema ajustado + Mais roteiros.

Sessao 3 - Treinamento & Entrega (2-3h)

  • Treinamento completo para uso autonomo.
  • Entrega do banco final de historias.
  • Geracao do lote final de roteiros.
  • Documentacao para consulta futura.
  • Formato: hands-on com voce operando o sistema.

Voce recebe: 20-30 Roteiros Finais + Documentacao + Sistema 100% Operacional.

Cronograma total: 3-4 semanas.
